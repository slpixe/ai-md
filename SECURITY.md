# Security policy

## Supported versions

Security fixes are provided for the latest published version. Users should upgrade to the newest release before reporting an issue that may already be resolved.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/slpixe/ai-md/security/advisories/new). Do not open a public issue containing exploit details, credentials, private repository contents, or other sensitive data.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

If private vulnerability reporting is temporarily unavailable, contact the maintainer through the GitHub profile without including sensitive details in a public message.
